# Project: TLPS Youth｜關於我轉生到同樂宇宙這檔事

（原名 Tlps-live：同樂小志工・校園生活。這一次的同樂校園生活，由你定義！）

宜蘭縣員山鄉同樂國小的 3D 校園生活遊戲。學生在校園裡當「小志工」：每日任務（種花、澆水、打掃）、週活動（資源回收）、幫校護／愛心志工／工友的忙。之後會從「時光門」開啟回到過去、前往未來的任務與闖關。

以「同樂3D校園 v286」為基底（人物、場景、導航沿用）。

## 遊玩規則（第一版）
- **視角**：預設第三人稱；右上可切第一人稱／鳥瞰。電腦 WASD 移動、Shift 跑、空白鍵跳、**F 互動**；手機左搖桿，靠近目標出現橘色互動鈕。
- **每日任務**（每天換新）
  - 🌱 種花：到菜園花圃種 1 株（6 種花，澆水 3 天開花，開花後可採收進花冊）
  - 💧 澆水：到水龍頭裝水（一次 3 桶），替 3 個花圃澆水
  - 🧹 打掃：撿起校園裡 5 件垃圾（每天 7 件，位置每天不同）
  - 💚 小志工：幫校護（急救包）、愛心志工（愛心餐籃）、工友（水龍頭漏水）其中一位完成請託，每天輪替
  - 全部完成：額外加分並累計連續天數；點數累積可升級稱號（小小志工 → 校園之星 → 同樂小英雄）
- **週活動：資源回收週**（每週一換新）：撿 10 件回收物（含 2 件不可回收的），到資源回收站分到「紙類／塑膠／金屬／玻璃／一般垃圾」，答對 10 件獲得週徽章。
- **進化階級（等級曲線）**：LV 上限 100，累積點數 ≈ 0.672 × (LV−1)^2.48（LV20 約 1,000、LV40 約 6,000、LV60 約 16,500、LV80 約 34,000、LV100 約 60,000，設計目標是約小學六年達到滿級）。
  - 五階：基本（灰）Lv.1–19 新轉學生 → 優良（綠）Lv.20–39 積極學習者 → 高等（青）Lv.40–59 社團小達人 → 傳奇（紫）Lv.60–79 宇宙探索者 → 史詩（金）Lv.80–100 同樂宇宙的傳奇。
  - 到達等級即自動進化，頭像換成對應階級的造型（25 款）；之後會再加進化試煉（社團、宇宙裂隙等）。
  - HP 上限 100＋每級 2、MP 上限 30＋每級 1.5、背包格數 12＋每 4 級 1。
- **角色介面（模組 1）**：左上任務板顯示 LV／EXP／HP（體力）／MP（靈感）；按 🎒 或鍵盤 **B** 開啟角色與背包面板。
  - LV 由累積點數決定，升級會補滿 HP／MP，並增加 HP／MP 上限與背包格數。
  - HP：種花 4、澆水 3、採收 2、撿垃圾 2、撿回收物 1；每 2 秒恢復 1，每天重置；到水龍頭喝水 +10，或請保健室校護恢復（每天 2 次）。
  - MP（魔力）：完成任務會增加、緩慢自然恢復，預留給之後的社團、迷你遊戲與宇宙裂隙。
  - 背包：顯示回收物、花朵與任務道具，格數隨等級增加。
- **五角屬性（模組 2）**：📚學業、💪體能、✨魅力、💡靈感、🤝社交，在角色面板（B）以雷達圖顯示。
  - 成長方式：體能←澆水、採收、撿垃圾與回收物；學業←回收分類答對、完成資源回收週；靈感←種花、完成每日任務；魅力←採收花朵、完成校園人員請託；社交←每天與每位校園人員對話、完成請託。
  - 每種屬性每天最多從日常行動獲得 10 點（避免刷分）；選定前世身分會得到對應屬性 +5。
  - 效果：體能每 10 點 HP 上限 +4；靈感每 10 點 MP 上限 +4。其餘屬性達到 20 點會標示「已達標」，對應的圖書館志工、校隊隊長、學生會長、社團創設、好友系統之後開放。
  - 角色頭像：小樂（勇者）、小同（偶像）、小創（工程師）、小味（廚師）、小知（魔法師）對應五種前世身分。
- **前世身分（轉生天賦）**：第一次進入校園時，從五種前世身分選一個（或讓宇宙抽籤），選定後不能更換：
  - ⚔️ 傳奇勇者「勇者之力」：水桶一次可裝 5 桶水
  - 🎤 星光偶像「星光魅力」：完成校園人員的請託，得 20 點（原本 10 點）
  - 🔧 天才工程師「天才巧手」：每撿起 1 件垃圾，多得 1 點
  - 🍳 異世界廚師「花朵入菜」：採收花朵，每朵多得 3 點
  - 🔮 大魔法師「過目不忘」：資源回收分類時，正確的桶子會亮起 ✨

## 上線步驟（GitHub Pages）
1. 建立新的 repository（例如 `tlps-live`），把本資料夾**全部檔案**上傳到根目錄。
2. Settings → Pages → Branch：`main` / `(root)`。網址：`https://hsiao103.github.io/tlps-live/`。
3. **Google 登入**：沿用 `auth-config.js` 內已設好的 Client ID 即可——「已授權的 JavaScript 來源」是網域層級（`https://hsiao103.github.io`），同一網域下的新 repo 不必再改。
4. （選用）**雲端存檔（Supabase）**：
   1. Supabase 建立專案（Project Settings → API 取得 Project URL 與 anon public key）。
   2. Authentication → Providers → Google：啟用，Client ID 填 `auth-config.js` 的 clientId，並開啟「Skip nonce checks」。
   3. SQL Editor 執行 `supabase.sql` 建立資料表與權限。
   4. 把 Project URL 與 anon key 填進 `live-config.js` 後重新上傳。
   5. 玩家登入後進度自動同步，右下角顯示「☁ 已同步」；未設定時顯示「本機存檔」。

## 安全性與限制（請務必了解）
- 登入是**純前端把關**：能擋一般使用者，但 `play.html` 檔案本身是公開網址，懂技術者可繞過登入直接遊玩。遊戲內容不含機密，影響有限。
- 點數與進度存在使用者端，**無法防止同學自行修改**；若要用來正式評量或競賽，需改成由伺服器（Supabase Edge Functions／RLS）計分。
- 雲端存檔有 資料表 RLS 規則：每個人只能讀寫自己的資料。若要讓老師看全班進度，見 `supabase.sql` 內的選用規則（請只列特定老師帳號）。
- Google 登入無法在 claude.ai 預覽網域使用，需在自己的 GitHub Pages 網址測試。
